# Provenance

`uniform-passwords` was independently authored from a supplied behavioral contract and synthetic tests. Its implementation uses Python standard-library facilities and declares no runtime dependencies.

No OneDrive or `nauth` source tree was accessed for this work. Tests and documentation contain no generated password fixtures or copied credentials.

Public source repository is <https://github.com/otrumb/uniform-passwords>. No package upload, tag, release, or PyPI publication is authorized or claimed.
